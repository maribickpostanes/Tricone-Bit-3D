# 3D Interactive Tricone Bit Visualization (STEP file) using Python
This repository hosts a proof-of-concept, interactive 3D Tricone Drill Bit plot visualized with Plotly from a STEP file. Optimized specifically for web viewing, it allows you to rotate and inspect the model's complex geometry in your browser.

Github Pages Link: https://maribickpostanes.github.io/Tricone-Bit-3D/
